# مراجعة هندسية قاسية — School Manager v4

## الحكم قبل الإصلاح

النسخة الأصلية كانت **نموذجًا وظيفيًا جيدًا للتعلم** وليست نظامًا جاهزًا للاستخدام المؤسسي. التقييم التقريبي قبل الإصلاح: **5.5/10**.

### أهم أسباب الرفض في Code Review

1. **الحذف عبر GET**: عملية مدمرة يمكن تنفيذها من رابط؛ غير مقبول. تم تحويلها إلى POST + CSRF.
2. **تسجيل الخروج عبر GET**: سلوك غير مثالي وقابل للتفعيل بالروابط الخارجية؛ تم تحويله إلى POST + CSRF.
3. **جلسة غير مكتملة**: كانت هناك بداية جيدة للحماية، لكن لا توجد حماية متكاملة من محاولات الدخول المتكررة، ولا تحقق من حالة الحساب. تم إضافة `is_active` و`login_attempts`.
4. **الصلاحيات كانت مخلوطة بين الدور والواجهة**: تم تثبيت RBAC + overrides فردية، مع فحص الخادم قبل كل عملية.
5. **النموذج الأكاديمي كان مسطحًا**: `grade` نص عام لا يكفي لإدارة مدرسة متعددة المراحل والشعب. أضيفت المرحلة والصف والشعبة والعام والسعة، إضافة إلى علاقات المادة/المعلم/الشعبة.
6. **دفعات الأقساط كانت تسمح منطقيًا بتسجيل مبلغ أكبر من المتبقي ثم تقليل الرصيد داخليًا**؛ هذا يسبب عدم تطابق مالي. أصبحت الدفعة الزائدة مرفوضة.
7. **رفع الصور يحتاج طبقات أكثر من فحص الامتداد**: تم اعتماد MIME + `getimagesize` + اسم عشوائي + حد حجم + حماية مجلد الرفع من PHP.
8. **التحقق من المدخلات كان موزعًا وغير متسق**: تم تعزيز التحقق الخادمي وإضافة أدوات موحدة للتاريخ والأطوال.
9. **لا توجد بنية كافية للتدقيق**: أضيف `audit_logs` وتسجيل للعمليات الحساسة.
10. **الواجهة جيدة كبداية لكنها ليست Mobile-first فعلية**: تمت إعادة CSS وإدارة الـ Drawer والـ Overlay والـ focus والحركة والوضع الداكن.

## الأداء

- الاستعلامات الأساسية تستخدم Prepared Statements.
- أضيفت فهارس على الأعمدة المستخدمة في البحث والربط والتاريخ.
- تجنبنا إدخال ORM أو Framework ضخم لأن المشروع مخصص لـ XAMPP محليًا.
- ما زالت بعض الصفحات تعرض قوائم كاملة؛ إذا وصل عدد الطلاب إلى عشرات الآلاف يجب إضافة Pagination وخيارات بحث/فلترة على مستوى SQL بدل تحميل جميع الصفوف.
- التقرير والبحث العام يجبان أن يبقيا محدودين بالنتائج عند التوسع.

## حدود ما تم إصلاحه

لا أدعي أن النظام أصبح "بلا أي خطأ ممكن"؛ لا يمكن هندسيًا ضمان ذلك دون تشغيله ضد بيئة MySQL الفعلية واختبار قبول شامل. ما تم هنا هو رفع جودة المصدر والبنية وقابلية الاختبار، مع إبقاء المعمارية بسيطة.
